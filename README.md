# DATAMAT

Landing page da DATAMAT - Consultoria de Business Intelligence.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Framer Motion

## Scripts

```bash
npm run dev      # Desenvolvimento
npm run build    # Build produção
npm run preview  # Preview build
npm run lint     # Lint
npm run test     # Testes
```
